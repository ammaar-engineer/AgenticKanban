# Fix layerIndex to use board detail data

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Make `KanbanLayer` receive `layerIndex` as a prop from `KanbanBoard` (which has the detail data) instead of computing it from the local zustand store (which has empty layers).

**Problem:** `kanban.layer.tsx` reads `boards` from `useKanbanStore` to compute `layerIndex` via `useMemo`. But the store's boards have empty `layers[]` (from the list endpoint), so `layerIndex` is always `-1`.

**Solution:** Pass `layerIndex` as a prop from `kanban.board.tsx` (which has `detail.layers` from `useBoardDetailQuery`).

---

## Step-by-Step Plan

### Task 1: Update KanbanBoard to pass layerIndex

**Files:**
- Modify: `client/src/components/app/kanban.board.tsx`

In the `layers.map()`, compute index and pass it as prop:

```tsx
layers.map((layer, index) => (
    <KanbanLayer key={layer.id} boardId={board.id} layer={layer} layerIndex={index} />
))
```

### Task 2: Update KanbanLayer to accept layerIndex prop

**Files:**
- Modify: `client/src/components/app/kanban.layer.tsx`

1. Add `layerIndex` to props type
2. Remove `const boards = useKanbanStore(s => s.boards)` and the `useMemo` for `layerIndex`
3. Use the prop directly
